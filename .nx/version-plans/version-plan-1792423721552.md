Creating an Android emulator and installing missing SDK packages no longer need `bash`: Harness runs `avdmanager` and `sdkmanager` itself, answering their prompts on stdin, and writes the emulator's files directly. The emulator directory comes from `ANDROID_AVD_HOME` or the user's home directory, so it no longer depends on `HOME`, and a configured `ANDROID_AVD_HOME` is kept for the tools Harness starts.
